## 🚀 How to Run the Platform

1. **1-Click Launch on Windows:**
   Double-click **`START_STUDIO.bat`** in this folder!  
   It opens the new front page automatically in your default browser.

2. **Or via Terminal:**
   ```bash
   node server.js
   ```
   Open: **`http://localhost:3000`**
